How aliases work

With the drawing visible and no text field focused, type a command alias, then Enter or Space. Example: L then Enter starts Line. Aliases separated by “or” are alternatives; keys joined by “+” are pressed together. Ctrl/Cmd means Ctrl on Windows or Command on Mac.
