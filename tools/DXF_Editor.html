Keyboard shortcuts

Command aliases follow the AutoCAD (ENU) conventions.

How aliases work

With a drawing open, just start typing — the console at the bottom picks up the letters. Confirm with Enter or Space to run the command, Esc to cancel. Example: type L then Enter to start a line, TR to trim.

Copy between drawings

Open a second DXF Viewer browser tab and load the other drawing. Select objects, press Ctrl+C, switch tabs and press Ctrl+V — layers and blocks come along, and the pasted objects stay selected so you can move them right away with M. Objects paste at their original coordinates, and if a block with the same name already exists in the target drawing, the target's version is used.

Import PDF vectors
