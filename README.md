## What you will find:
[**liteAECO**](https://liteAECO.com/tools/dxf-editor.html) · [live](https://liteAECO.com/)
> Here you can find all the files and documentation of the DXF Editor and Compare to continue the development, including all files to deploy it on your own server.
- DXFScope
  - DXF Viewer and editor
  - Classic AutoCAD layout
  - Basic 2D drawing tools
  - Support for dimensions, text and blocks
  - Paper space with support for CTB files
  - Layer visibility states
 
- DXFCompare
  - Compare 2 DXF drawings with several options
  - Overlay, Side by Side and Swipe-view
  - Make changes more visible with colors
  - Align drawings
  - Toggle layers
  - Compare layouts and model space

- Source repo, not dist/. (2026-10-19).
